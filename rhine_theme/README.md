# Rhine UI · 复刻初版 v0.1

[主题文件](Rhine-UI-Study-v0.1.klwp) · [全部预览](previews/all-screens.jpg) · [逐界面调研](docs/research.md) · [38项需求追踪](docs/requirements.csv)

这是根据所提供视频和糖果城小程序资料独立重做的 KLWP 安卓动态壁纸预设。包含首页、控制中心、应用、天气、音乐、日历、外观设置、功能设置，以及天气详情和加载状态。预设不加锁，图片和入口可以自行调整。

**当前状态：文件结构和静态布局已检查，尚未在目标安卓手机上导入验证。** 预览为布局示意，不能作为已经运行成功的证据。

## 导入

1. 将 `Rhine-UI-Study-v0.1.klwp` 传到手机。
2. 在 KLWP 中选择“加载预设 → 导入”，选中这个文件，保持 `.klwp` 文件完整，不要解压。
3. 先在编辑器预览并保存，再设置为动态壁纸。主页按一页布局设计。启动器图标可能盖住壁纸的点击区域，应给主题留出空白主屏。
4. 在 KLWP 全局变量中，`wall` 替换主页壁纸，`cover` 替换默认封面，`scene` 替换天气卡背景。默认壁纸是本次生成的插画。
5. 根据需要在 KLWP 设置里配置位置/天气源、日历来源和音乐播放器。实时信息取决于相关权限与数据源。

导入方式参考 [官方 FAQ](https://docs.kustom.rocks/docs/faq/faq_klwp/)。不同发行版对外部预设导入的要求不同，按 [官方 KLWP 下载说明](https://docs.kustom.rocks/docs/downloads/download-klwp/) 选择合适版本。

## 点击路径

- 首页圆形时钟或底部 Dock：控制中心。
- 侧栏从上至下：天气、音乐、日历、应用。
- 控制中心“设置”：两页主题设置。
- 功能页左上箭头：回首页；顶栏可切换天气、音乐和日历。
- 天气曲线节点：展开详情；黑色详情面板：收起；左右箭头：翻预报。
- 音乐底部三个按钮：上一首、播放/暂停、下一首。
- 月历日期：选择当天；左右箭头：切月；年进度右箭头：回今天；日程加减：切条目；右下箭头：打开系统日历。
- 加载页可点击“跳过”，也可在外观设置里关闭。

## 需要依据手机适配的部分

- 微信两个快捷按钮目前打开微信，不承诺直达付款码/扫码；可在 KLWP 对应图层的触摸设置中选择手机提供的快捷方式。
- 支付宝、相机、系统设置、日历的打开行为需要核对实际安装版本。
- 歌词、SO2、真实天气预警仅有全局文本接入口，默认显示未接入/未知。
- 完整3D卡片动效、逐行歌词同步、精确反向动画尚未还原。
- 以720×1600设计画布等比适配普通竖屏，超宽/折叠屏、刘海和系统手势区域需要实机调整；“避开Dock”只提供统一上移。

说明与证据见 [调研文档](docs/research.md)。修订需要手机型号、Android/系统版本、启动器和 KLWP 版本。

## 文件

- `.klwp`：导入手机的主文件。
- `preset.json`：可编辑的完整预设定义。
- `assets/`：独立插画、图标和开放许可字体。
- `previews/`：按同一布局定义生成的示例数据预览。
- `docs/`：逐界面证据、需求清单与验证结果。
- `src/`：构建与结构检查工具；不会调用原主题的锁定源码。
