# 莱茵 UI：素材识别与复刻需求

调研日期：2026-09-08。范围是你提供的小红书视频，以及电脑版「糖果城」小程序已缓存的主题介绍图片与动图。没有取得原版 KLWP 源文件，也没有把小程序本身误当成主题界面。

## 结论与来源边界

共识别出 **8 个主要页面/面板**：首页、控制中心、应用、天气、音乐、日历、外观设置、功能设置。另有 **天气详情展开**、**加载过渡**两个独立状态。深浅配色和不同人物壁纸属于样式变体，不另算功能页。

小红书视频长约 8.7 秒，整理了 35 个时间点的关键帧。小程序的 5 个缓存文件实际是 GIF，已展开为 393 帧并制作分镜表；它们补齐了视频没有展示完整的音乐、日历和加载过程。不是把同一页面换几张壁纸算成“更多界面”。

## 信息结构与交互需求

首页通过侧栏进入天气、音乐、日历和应用页；底部控制入口展开控制中心；设置进入外观和功能两页。天气/音乐/日历共享顶栏。天气详情保持在天气上下文内，不应变成一个独立全屏页面。返回时恢复首页。

天气曲线应随预报变化，并限制在数据源提供的天数内。没有数据时应显示未知或空状态，不应使用视频中的城市、28°C 或空气质量数值作为真实值。日历应随月和年份变化，支持闰年；音乐应以系统播放器状态驱动图标、封面和进度。

画面结构的关键不是普通圆角卡片：它使用硬边矩形、斜切块、细分隔线、非对称控制中心、窄侧栏、斜向 Dock、大数字和小型英文辅助字。功能页有低对比壁纸透出和细点纹理；荧光绿主要用于空气质量、日程和提示，蓝紫/金色主要来自主页配色。

## 动效需求与首版实现

| 观察到的效果 | 复刻首版 |
|---|---|
| 控制中心各卡片按顺序展开 | 已定义 KLWP 根层级错峰淡入与位移 |
| 应用页进入时 Dock 转平 | 已定义整组 15° → 0° 旋转 |
| 天气/音乐/日历按模块装配 | 已定义错峰入场；具体时序需真机调整 |
| 天气卡翻页、右侧详情展开 | 数据翻页和详情开关已实现定义；曲线滑动轨迹未逐帧等同 |
| 底部绿色条扫过 | 用绿色覆盖层淡出近似；不是原版扫描着色器 |
| 中央加载标志与进度 | 独立重绘，约 2 秒自动结束，可关闭或跳过 |
| 重力感应的卡片空间效果 | 首版只定义轻微壁纸视差，未实现完整 3D 卡片倾斜 |
| 连续歌词高亮和滚动 | 保留歌词文本入口，逐行同步尚未实现 |

演示动图的模块装配约 0.8–2.5 秒；它可能经过剪辑，不能据此当作原工程里的精确动画参数。原版反向收回、弹性曲线、着色器和资源图形未完整复原。

## 首版交付与已知差异

交付 `Rhine-UI-Study-v0.1.klwp`，可编辑、不加锁的独立 KLWP 预设；8 个主页面、详情与加载状态、43 个全局项和 27 个根层。图片预览来自同一份布局定义，使用清楚标注的示例数据，**不是安卓实机截图**。

默认人物壁纸为本次生成的蓝紫色独立插画，不是原视频的原图。应用图标为简化默认图形；天气卡使用独立绘制的建筑网格背景，原视频的城市航拍图未取得。加载标志也为独立重绘。你可以在全局变量中替换壁纸、默认封面和天气卡背景。

目前天气、电池、资源、媒体、日历使用 KLWP 本地函数定义；未在安卓引擎实际执行过。SO2、真实预警、歌词没有可靠来源，保留空值/接入口。微信付款码与扫一扫默认先打开微信；支付宝链接和所有启动应用操作仍需依据手机上安装的版本验证。

已通过 ZIP/JSON 完整性、内嵌资源、全局引用、公式定界符、页面目标、动画层级检查，以及 60 个跨年/闰年月历算例。算例验证的是日期算法，不能替代 Kustom 公式引擎测试。完整结果见 [验证记录](validation.json)。

仍缺手机型号、系统版本、启动器和 KLWP 安装信息，因此尚未完成导入、触控、刘海/手势避让、实时权限与性能验收。本文件是可审阅的复刻初版，不能标为“与原版完全一致、真机可用已验证”。
