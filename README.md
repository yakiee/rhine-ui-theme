# Rhine UI · 庄方宜手机主题

用于私有备份和跨电脑继续修改的 KLWP / HyperOS 主题工程。

## 从哪里接手

1. 先读 [当前手机状态](rhine_exact/CURRENT_PHONE_THEME.md)。文件最上面的记录优先。
2. 再读 [跨电脑接手与恢复](docs/RESTORE.md)。
3. 最近完成的是 [Dock 打开后翻页的关闭逻辑](rhine_exact/output/open-dock-swipe-20260915/VERIFIED.md)。

**手机上的当前版本由基底和多次原生编辑组成，旧 `.klwp` 不是最新手机的完整导出。** 本仓库保存源码、基底、组件补丁、素材和已知参数，不能承诺在空白手机上一键恢复。换电脑继续修改同一部手机时，应保留手机正在使用的主题。

## 当前交互

- 原生澎湃桌面第 2 页为主题页，保留底部斜条；翻页时斜条收到底部并放平。
- 侧工具栏从上到下：电话、信息、浏览器、相机、打开 Dock。
- Dock 打开后，翻页、点击外部及离开桌面按当前状态逻辑关闭；不增加多余返回按钮。
- 时间、电量等使用设备数据；庄方宜桌面背景和终端封面位于 `rhine_exact/assets/zhuangfangyi/`。
- 手机主屏幕使用 KLWP，锁屏独立保留月球超级壁纸。

## 目录

| 目录 | 用途 |
| --- | --- |
| `rhine_exact/src/` | 布局、动画和导出源码，含历史迭代 |
| `rhine_exact/assets/` | 字体、图形、当前人物素材 |
| `rhine_exact/output/` | 可编辑预设 JSON、原生组件剪贴板和修改记录 |
| `android-preview/` | 实机同步、观察及验证脚本，含历史一次性操作 |
| `rhine_exact/design/` | 设计探索；人物互动 / Live2D 尚未实现 |
| `rhine_theme/` | 最初版本的历史源码与说明 |
| `docs/` | 接手说明与备份检查 |

模拟器、SDK、安装包、录屏、手机 UI 转储及调试日志不进入 Git。历史文档引用的部分验证截图/视频仅留在原电脑；引用不代表这些附件已备份。

运行 `python tools/check_backup.py` 可以检查必需文件、原生剪贴板结构和基底包，并生成本机备份清单。该检查不会连接或操作手机。

素材来自用户提供的参考及定制生成内容。本工程用于个人私有备份，不授予第三方角色、字体或原始素材的再分发许可。
