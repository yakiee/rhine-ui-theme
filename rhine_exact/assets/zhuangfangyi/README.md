# 庄方宜壁纸与封面

- `wallpaper-portrait.png`：依据用户提供的横幅插画生成的竖屏壁纸。保留抬臂斜身姿势，强化前景手臂与衣摆的透视，黄绿底色；不是原始官方壁纸。
- `terminal-cover.png`：用户提供的庄方宜头像卡，原文件保留，由 KLWP 封面框裁切显示。
- 已通过当前 KLWP 编辑稿中的 `wall` 和 `termcover` 图片选择器分别选入并保存。
- `desktop-verified.png`、`terminal-verified.png`：手机上实际显示的验证截图。

## 生成构图要求

约 1200:2608 竖屏比例。参考用户第二张横向插画，庄方宜保持黑青长发、红色分枝角、绿金眼睛、白黑战术服装和橄榄绿下装。人物斜向构图、低机位、近大远小；一只手臂抬到脑后，近景手臂从左下伸出。黄绿与暖白背景配等高线、少量网点与青色碎片。脸部放在上半屏，为右侧工具栏和底部斜条保留空间；不生成手机 UI、文字或水印。
