# v0.13.2 使用说明

## 终端

蓝色区按参考图拆成三张独立卡片：左侧支付宝为通高按钮，中间付款码、右侧扫一扫共用文字基线；上方深色栏为快捷支付。各卡片分别带顶/左亮边、右/下暗边与背后阴影，按压时文字、图案、边缘一起轻微内倾及缩小。九宫格方向采样，约 360 毫秒复位。

| 区域 | 点击动作 |
|---|---|
| 日期时间 | 主题日历 |
| 电池小图标、温度区域 | 系统电池用量 |
| CPU、终端设备信息 | 系统设备信息 |
| RAM | 系统应用管理 |
| ROM | 系统存储设置 |
| 系统、主题 | 系统设置、主题外观与交互 |
| 支付宝、付款码、扫一扫 | 各自对应的支付宝入口 |
| 快捷支付标题栏 | 支付宝首页 |
| 电话、文件、微信 | 对应应用 |

## 日历

参考签到面板的深灰磨砂底、大号日期、黄色选中格与侧轨。月历按真实年月排列，支持选日、翻月、回到今天；下方显示所选日期及可读取的系统日程，系统日历按钮打开手机日历应用。没有把游戏奖励或签到状态伪装成真实日历数据。

## 天气

参考关卡界面的折线和六边形日期节点。竖屏中，上半屏为五天日期节点，下半屏为概况；点击节点后，日期卡变为白底蓝标，并滑入独立天气详情。支持上一天、下一天和关闭详情。温度、天气、降水概率、风速、湿度接 Kustom 实际天气数据，缺少时显示 —。

## 验证与当前状态

常规版已应用到模拟器，另提供关闭重力视差版。已检查日期选择、翻月、回到今天、节点选择及切换、详情关闭；设备、电池、应用管理、存储入口实际打开成功，日历应用打开其首次引导页。录屏验证蓝色三块独立按压。

模拟器没有可用天气及可读取日程，画面保持空状态；未安装支付宝、微信，相关第三方跳转尚未实测。未变更位置、日历或通知读取权限。

实现接口参考：[Kustom 天气预报](https://docs.kustom.rocks/tags/wf/)、[Kustom 日历事件](https://docs.kustom.rocks/tags/ci/)。
