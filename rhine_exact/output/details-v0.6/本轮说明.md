# 莱茵 UI 细节校准 v0.6

本轮继续以用户提供的参考为依据，主要优化天气、音乐和日历。输出仍是可编辑 KLWP 主题，已在电脑模拟器中应用。

## 本轮修改

- 天气：依据小程序清晰海报补齐空气质量连线、四个节点、加粗指标、单位和英文说明；天气页码改成五个原生描边方块并补上两侧横线；修正警示符号、斜体温度数字和 DEGREES CELSIUS 标签。
- 音乐：使用当前参考帧中的封面，并改正 KLWP 图片缩放模式和顶部裁切；分开曲名、歌手、细线波形和五行歌词，并修正“曇った顔が似合うから”的文字。增加斜纹分组退去、四角标记及封面展开，随后显示曲名、歌词和播放控件。
- 日历：调整日期与标题字重，补上参考中的日期边框和年进度卡阴影，保留点击日期的行为。

## 验证

实际检查了设置按钮中心/边缘、天气详情关闭返回、音乐播放/暂停及恢复、日期选择、各页返回。图像验证结果见 runtime-check.json；压缩包、嵌入资源、主题格式和节点检查见 package-check.json。

本轮仍沿用预览数据。歌词、波形和音乐进度是参考示例，尚未随真实播放器更新；人物壁纸与天气场景也仍是替代素材。因此这版是继续校准的预览，不是原版等价成品。

## 使用

Rhine-UI-details-v0.6.klwp 包含图片和字体，可继续逐项编辑。电脑模拟器已应用本版；手机上放入 Kustom/wallpapers 后，在 KLWP 中加载并设为动态壁纸。v0.5 保留在上一版目录，便于比较或回退。
