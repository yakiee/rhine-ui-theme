# 莱茵 UI 原生主题返工版 0.2

当前产物是安卓 KLWP 桌面主题工程，文件为 [Rhine-UI-native-v0.2-unfinished.klwp](Rhine-UI-native-v0.2-unfinished.klwp)。它仍是未完成返工版，不能作为一比一成品验收。原壁纸和8个应用图标尚未绑定，首页相应位置会空缺；字体、功能图标、加载标志仍有近似，已在 Android 11 模拟器中导入并渲染，但页面重叠、动画状态错误，尚未通过运行验收。

本轮将原先多个页面共用的淡入位移动画拆成60个独立原生动画层。修改落在主题包内。可见层在离开页面后保留用于退出动画，触摸副本按当前页面关闭；这两项仍需真机确认。

|---|---|---|

| 控制中心 | 压暗、设备状态、四组卡面与文字分别展开/退出 | 原遮罩与卡片姿态的逐帧精调、点击反馈 |

## 使用与检查范围

主题使用 KLWP 原生的全局变量、动态数据、触摸动作与动画，无网页运行依赖。需要在安卓 KLWP 中导入后配置尚未绑定的壁纸与图标；当前包适用于继续编辑和真机排查，尚不适合直接作为日用成品。

[检查记录](validation.json) 仅验证文件结构、资源引用、分层后的1003项静态数值坐标、动画定义所在层级与触摸区域的状态条件；未执行 KLWP 公式解析、安卓渲染或动态点击，不能据此声称实际运行正确。

完整要求：[全主题还原要求](../../REQUIREMENTS.md)。逐层追溯：[全页动效覆盖表](../../analysis/all-page-motion-coverage.json)。原布局输入与生成脚本保留在工程内，生成操作不会覆盖上轮审阅源稿。

动画机制依据：[Kustom 原生动画说明](https://docs.kustom.rocks/docs/reference/animations/animations_explained/)和[复杂动画说明](https://docs.kustom.rocks/docs/reference/animations/complex_animation/)。原主题补充参考：[糖果城商品页](https://www.tgcday.com/h-pd-501.html)。
