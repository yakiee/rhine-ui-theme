# 莱茵 UI · 小米澎湃 KLWP 安装说明

版本：v0.13.51（基于已验证的 v0.13.50）。

这是通过 KLWP 运行的可编辑桌面动态壁纸。包含现有布局、跟手斜条、终端、天气、音乐和日历。需要 KLWP 及支持动态壁纸点击、壁纸滚动的启动器。不是直接导入小米「主题壁纸」的 MTZ，不修改系统图标、通知栏或锁屏。

## 1. 安装和导入

1. 手机安装官方 KLWP。没有 Google 服务可选择官方 AOSP 版本：支持广告、不要求 Pro 密钥。下载页：https://docs.kustom.rocks/docs/downloads/download-klwp/
2. 将本压缩包解压到手机。里面的 `.klwp` 文件不要再次解压。
3. 打开 KLWP，按提示选择工作文件夹，进入「加载预设」→「导入」，选择 `Rhine-UI-HyperOS-v0.13.51.klwp`。
4. 加载后保存，按系统提示设为主屏幕动态壁纸。若倾斜视差不适合你的手机，改导入文件名带 `-off` 的版本；其他交互相同。
5. 启动器至少保留两个桌面，启用壁纸滚动，并让 KLWP 中设置的屏幕数量与启动器一致。
6. 第 1 页放普通 App 图标，第 2 页作为主题主页，尽量留空避免图标遮挡主题按钮。全局变量 `homepg` 默认是 `2`，如主页放在别的页，需要修改它。

澎湃自带桌面是否把滚动偏移和点击传给动态壁纸，需要在具体机型和系统版本上确认。若滑动时斜条不跟手，或主题按钮没有反应，先检查启动器的壁纸滚动/点击支持；这些能力无法靠修改预设强制开启。可以使用支持这些能力的启动器，但替换系统桌面后的手势体验也需在手机上确认。

## 2. 怎么操作

- 主题主页右侧竖 Dock，从上到下：天气、音乐、日历、终端（四宫格）。
- 在主题主页手指向右划，进入左侧正常应用桌面；斜条跟随拖动下移、转平，文字淡出，成为底部 Dock 背景。向左划回主题主页恢复。
- 点击四宫格展开终端，终端左上「返回」收起，右上「主题配置」打开 KLWP 编辑器。
- 天气点节点看详情；日历点日期、箭头切月；音乐先在播放器播放，再使用上一首/暂停/下一首。
- 功能页使用页面内返回/关闭按钮；从终端进入的功能页返回终端，从主页进入的返回主页。系统返回键不代替主题内部返回。
- 普通应用桌面的图标由启动器管理，需要你自行摆放，不包含在 KLWP 预设里。

## 3. 小米应用入口和个性化

打开终端→主题配置→全局变量，修改后保存：

| 项目 | 用途/默认值 |
| --- | --- |
| `galleryapp` | 相册 App 包名，默认 `com.miui.gallery`，同时控制第一行左侧和相册封面入口 |
| `fileapp` | 文件管理 App 包名，默认 `com.android.fileexplorer` |
| `search` | 系统按钮对应 App 包名，默认 `com.android.settings` |
| `musicapp` | 留空显示主题音乐页；填写播放器包名后直接打开该 App |
| `musicsub` | 音乐按钮副标题 |
| `wall` | 主壁纸 |
| `termcover` / `covertext` | 相册封面 / 封面文字 |
| `homepg` | 主题主页页码，默认 2 |

小米相册和文件入口按小米公开的应用清单配置；地区版本、替换过系统应用等情况可能不同。某入口无法打开时，把对应包名改为手机上实际安装的 App 包名。电话使用系统默认拨号入口，只打开拨号界面，不拨出电话。

终端顶端：时间打开主题日历，电池打开电池设置；CPU/RAM/ROM 分别打开设备信息、应用设置、存储设置。第二行是系统、音乐；蓝色三块分别是支付宝、付款码、扫一扫；最后一行是电话、文件、微信。灰色补位块和背景纹理为装饰。

## 4. 数据与运行

- 电量和时间读取运行手机的数据，不会保留模拟器的 100% 或日期。
- 「机温」是电池温度读数，不是 CPU 温度；实际数值由手机传感器提供。
- 天气需在 KLWP 设置位置和天气服务；日程需要日历数据及授权；音乐信息/控制需要播放器与 KLWP 相应设置。未取得数据时会显示空值或等待。
- 支付宝、微信入口需要对应 App 已安装；深层入口能否打开取决于 App 版本和系统允许情况。
- 如果息屏后不更新，检查手机对 KLWP 的后台和电池限制；若跳转被拦，按系统提示检查相关权限。按实际需要设置即可。

## 5. 验证范围

导出包已检查压缩完整性、内置图片/字体引用、无电脑绝对路径依赖。所有布局、真实数据公式、动画参数与 v0.13.50 一致，仅调整应用入口并增加相册/文件配置。

v0.13.50 的慢速往返滑动、取消滑动、终端展开收起已在 Android 11 模拟器验证。v0.13.51 的默认拨号动作已检查能被模拟器解析。小米相册/文件应用入口、支付入口和澎湃自带桌面的点击/滚动尚未在你的手机实测，不能视为已经通过 HyperOS 真机验收。包内预览来自 v0.13.50 模拟器，仅用于展示外观。
