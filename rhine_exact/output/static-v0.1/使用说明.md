# 莱茵 UI · 可编辑静态主题 v0.1

这一版用于核对最初页面浏览图中的静态布局。它是安卓 KLWP 桌面主题，已在电脑上的 Android 11 模拟器和 KLWP 3.82 AOSP 中实际导入、设置为壁纸并逐页点击验证。

## 文件

- `Rhine-UI-static-v0.1.klwp`：可导入主题，未锁定，包含字体及图片。
- `all-pages.jpg`：模拟器实际画面的十页总览。
- `screens/`：各页原始模拟器截图。
- `package-check.json`、`runtime-check.json`：打包与运行检查记录。
- 构建源文件：`../../src/build_static_theme.py` 和 `../../src/static_helpers.py`。

## 查看与切页

电脑桌面打开“莱茵主题预览”，模拟器已经设置好主题。

- 点左上时钟：控制中心。
- 点右侧四个图标：天气、音乐、日历、应用页。
- 点控制中心“设置”：外观设置；点上方页签进入功能设置。
- 功能页面顶部可以切换天气、音乐、日历；左上返回线回首页。
- 点天气卡片的白色温度标签：天气详情；点右上 × 收起。
- 点底部日期 Dock：切换控制中心与首页。
- 外观设置 → 加载动画 → 静态预览：查看加载页；点击加载页返回首页。

## 编辑

在 KLWP 中打开本预设，进入“项目”编辑各组。字体、文字、卡片、线条和点击动作是原生组件；图片是单独的位图组件。封面、应用图标和加载标志使用 KLWP 原生裁切，未把整页截图当作主题页面。

全局变量 `wall` 可更换人物背景，`scene` 可更换天气卡背景。应用图标和封面可在对应图片组件中更换。全局变量 `page` 为 0 首页、1 控制中心、2 应用、3 天气、4 音乐、5 日历、6 外观、7 功能、8 加载静态页。

## 本阶段范围与差异

这是静态首版，不是一比一完成版。包含八个主页面、天气详情和加载静态页，动画组件数量为零。时间、天气、音乐进度、日期和设备数据是参考用的固定演示数值；未接入实时数据、播放、支付或应用启动。部分设置仅用于保留参考布局；实际业务功能留待下一阶段。

人物壁纸和城市照片缺少原文件，当前使用基于参考画面由 imagegen 清理重建的临时资产，局部与原图存在差异。音乐封面、应用图标和加载标志来自参考画面的局部裁切，分辨率有限。字体、侧栏图标、空气质量微文字、日程卡装饰与加载页排版仍有差异。完整歌词未重建。

本次验证覆盖模拟器里的点击切页、返回、天气详情、加载静态页，截图已全部保存；尚未在实体手机上验收。
