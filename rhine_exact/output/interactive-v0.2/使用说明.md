# 莱茵 UI · 交互动画 v0.2

在已验证的可编辑静态主题上增加原生 KLWP 动画。静态 v0.1 文件保持原样；本版单独打包。

## 已加入的动画

- 首页时钟与功能侧栏淡入、展开和收起。
- 控制中心设备信息与卡片依次进入，返回时退场。
- 应用页使用参考测量轨迹展开和收回；Dock 同步旋转、上下移动。
- 天气卡横向展开，空气质量区域缩放出现，当日信息上移；详情面板滑动开合。
- 音乐封面展开，歌词和控制区分阶段出现；播放按钮可以切换图标并触发点击反馈。
- 日历、年进度和日程卡分阶段进入；日期可点击选中。
- 外观、功能设置切页过渡，选项切换有点击光环反馈。
- 首页进入天气、音乐、日历时显示约 0.8 秒加载过渡。可在外观设置里关闭；点“加载动画”标题可单独预览。

点击光环约 0.3 秒，普通入场约 0.22–0.45 秒，退场约 0.18 秒。画面静止后的布局延续静态版。

## 查看

电脑上的安卓模拟器已装入本版。点左上时钟打开控制中心，右侧图标进入天气、音乐、日历、应用；功能页左上返回首页。控制中心的“设置”进入主题设置。

`interaction-preview.mp4` 是模拟器实际操作录屏的精简版；`interaction-demo.mp4` 保存原始录屏。`Rhine-UI-interactive-v0.2.klwp` 是未锁定的可编辑主题。`screens/` 保存运行截图。

## 范围

这是一版基于参考重建的交互动画，不能视为原预设动画参数的一比一还原。应用页参考了此前测量的轨迹，其余时序及缓动为重建值。原字体、图片和装饰差异沿用静态版。

天气、歌曲、播放进度和日历仍是演示内容；播放按钮切换是视觉交互，不会播放音频。尚未接入实时天气、播放器、支付或应用启动。

## 编辑与检查

KLWP 中前 26 组是视觉层，后部标为“交互区域”的层负责点击。动画结束时视觉层仍保留在布局中，但透明；未激活页面的交互层会移除，避免挡住当前页面。请同时修改对应视觉元素和交互区域的位置。

构建源文件：`../../src/build_interactive_theme.py`。动画清单：`motion-coverage.json`。
