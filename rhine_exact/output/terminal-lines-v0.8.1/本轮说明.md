# 终端时间细线校准 v0.8.1

依据原始清晰动图 f_000019 的第 20、28、34 帧，补齐终端日期时间行左右两段白色细线：左段位于电池图标外侧，右段从时间文字外侧延伸到画面边缘；同时调整电池图标与左线的间距。

细线为原生可编辑形状，与设备状态栏共用透视、入场动画。随动版共用状态栏的重力视差，静止版保留切页动画。

- Rhine-UI-terminal-lines-v0.8.1.klwp：随动版。
- Rhine-UI-terminal-lines-off-v0.8.1.klwp：静止版。

本次仅针对遗漏的时间行装饰及相邻间距修正，其他布局延续 v0.8；不代表整体已达到一比一。
