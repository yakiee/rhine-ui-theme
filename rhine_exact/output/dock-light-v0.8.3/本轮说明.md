# 柔金光带 v0.8.3

以用户提供的明日方舟干员列表图为依据，修改底部 Dock 光带。

- 去掉宽而均匀的橙黄色实心条，收窄至卡片上沿。
- 使用 KLWP 原生连续透明渐变，叠加左侧琥珀暖光、中段浅金亮区。
- 半调网点向上逐渐缩小、变淡，保留网点开关与配色选项。
- 修正应用页展开后的光带落点，使其贴合横向 Dock。
- 保留终端两侧横线、三格电池、点击切页与原有重力视差。

release 为本轮最终包；off-release 为关闭重力视差的版本，保留切页动画。光带仍可在 KLWP 内逐项编辑。

结构校验：仅第 24 号根模块（光带）变化；其余页面模块、全局变量保持一致。已在模拟器查看主页、菜单页与应用页。此版本依据截图校准，未获得原主题素材，不代表完全一致。
