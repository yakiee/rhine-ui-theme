# 莱茵 UI · 斜面首页 v0.3

已安装到电脑上的 RhinePreview 安卓模拟器。打开桌面“莱茵主题预览”即可查看。

## 本版修改

- 右侧四个入口改为菱形面板，增加顶面、侧边和底部折角；点击范围同步重建。
- 时钟补上斜切底板与分段铭牌，保留参考图中的圆环、时间和 AM。
- 底栏保留 22.02° 斜向构图，增加密集穿孔高亮边与切角。
- 应用页展开时底栏转平；其他页面的交互和动画保持上一版。

## 如何操作

点击左上时钟打开控制中心；点击底栏返回首页。右侧菱形入口从上到下为天气、音乐、日历、应用。
应用页点击时钟返回控制中心。功能页点击左上箭头回首页。

导入文件：Rhine-UI-diagonal-v0.3.klwp。全部页面仍为原生可编辑 KLWP，未锁定。

## 验证

已在 Android 11 / KLWP 3.82 模拟器逐一检查入口、切页与返回。最后回到首页的画面与初始首页一致。
截图在 screens，录屏为 interaction-preview.mp4。

本版是依据最初浏览图并参考明日方舟界面风格的重建，不是原主题文件。壁纸与城市场景继续使用已说明的临时重建素材；时间、天气、音乐和日历仍为演示数据，动效参数并非原版。
