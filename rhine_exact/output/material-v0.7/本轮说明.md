# 莱茵 UI v0.7

本轮依据用户提供的明日方舟原版截图，继续调整可编辑 KLWP 主题的材质和控件层次。

- 主菜单：新增浅色棋子／阵列／六边形纹章、渐密网点、薄边与浅投影，保留已有卡片透视、动画和点击区域。
- 设置页：磨砂背景、半透明面板、深色矩形按钮、青色选中状态；深浅色模式分别适配文字与面板。
- Dock：新增局部暖金色辉光，调低光点亮度，保留原有切换和形变动画。
- 天气、音乐、日历等页面延续 v0.6，本轮未重新改变其布局与动画时间。

## 文件

- `Rhine-UI-material-v0.7.klwp`：可编辑主题包，已装入本机模拟器。
- `material-before-after.jpg`：主菜单与设置页的前后对比，每组左侧 v0.6、右侧 v0.7。
- `interaction-demo.mp4`：实际模拟器操作录像。
- `screens`：交互状态截图，14、15 为深色设置，16 为恢复浅色，17 为最终主菜单。

## 验证与范围

已检查主题包完整性、内嵌素材、深浅色切换、外观与功能标签页、金蓝配色、光点开关、倾斜菜单点击及返回路径。应用页 Dock 会打开主菜单，主菜单 Dock 再返回首页。

这版仍是基于视频和截图重建。壁纸素材及部分细节与原版有差异；天气、日期和音乐信息仍含预览数据，真实服务接入不属于本轮验证范围。尚不能认定为一比一还原。
