# Rhine UI v0.9.2 设备数据版

可编辑 KLWP 主题。数据读取运行主题的安卓设备；在模拟器里显示模拟器的数据，导入手机后显示手机的数据。

| 区域 | 数据来源与行为 |
|---|---|
| 时钟、终端时间、星期、日期 | 系统时间与 Kustom 的时区、语言及 12/24 小时设置，持续更新 |
| 电量数字、圆环、三格电池 | 安卓电量；100% 为完整圆环 |
| 终端温度 | 安卓电池温度，明确采用摄氏度 |
| 机型、Android 版本 | 当前设备系统信息 |
| CPU、RAM、ROM | Kustom 原生资源监测；ROM 表示内部存储使用率；不可读取时显示 — |
| 月历、今天、高亮、年进度 | 当前日期，支持跨月、日期选择、返回今天；年进度按当年实际天数计算 |
| 日程 | 原生系统日历源；须允许日历读取并选择日历，没有可读事件时显示空状态 |
| 天气、预报曲线、空气质量 | Kustom 已配置位置和天气服务；等待定位、服务配置及联网更新；缺失数据不使用示例数字 |
| 歌名、歌手、封面、播放进度和控制 | Android 媒体会话；须允许 Kustom 通知读取，播放器还需要提供对应信息 |
| 歌词、SO₂ | 原生接口没有可用字段，保留可编辑外部入口；未接入时明确显示缺失 |
| 深浅色 | 默认跟随设备系统，可在主题设置中手动切换 |

页面标题、操作按钮、单位与品牌文字仍保留为界面标签。

## 验证

已在 Android 11 模拟器导入并运行。核对时间与系统状态栏一致、机型 sdk_gphone_x86_64、Android 11、电量 100、电池温度 25°C。核对 2026 年 9 月、10 月切换、选择 9 月 18 日、返回 9 月 10 日、年进度 69% 和剩余 112 天。时钟已观察到跨分钟更新。CPU 接口不可用时显示 —。天气、歌曲、日程当前处于缺少权限或数据的空状态；真实天气更新、媒体播放和日历事件读取尚未完成验证。

自动审批拦截了授予定位、日历和通知监听权限的操作，尚未更改这些权限。需要用户明确授权后继续。

保留 v0.8.7 的全部 64 个根图层及所有动画轨迹，包含 Dock 光条贴合、边角修复和重力视差。无重力视差版仅沿用原先关闭传感器的配置，页面动画仍保留。
