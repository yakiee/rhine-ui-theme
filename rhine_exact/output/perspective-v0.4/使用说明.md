# 莱茵 UI · 透视主菜单 v0.4

本版修正点击 Dock 后出现的主菜单。终端、搜索、设置、支付宝及微信快捷选项采用同一透视平面，文字和点击区域跟随面板变形。首页、应用页和其他功能页沿用 v0.3。

已安装到电脑模拟器，并停在展开后的主菜单。单击 Dock 可以收起或重新打开；设置按钮进入外观设置；功能页左上箭头返回首页。

主菜单使用 KLWP 原生 3D Y 轴旋转 -25°，各行共用投影中心，并保留进出动画。文件未锁定，可编辑文字、图形、全局变量与动画。

已经验证：Dock 开合、设置按钮中央和倾斜边缘、设置页返回、连续开合后的最终画面。检查报告 runtime-check.json，录屏 interaction-preview.mp4。

搜索和支付快捷项仍为布局演示，未新增搜索或真实支付功能。天气、时间、音乐和日历数据仍为演示。壁纸和城市场景继续使用之前说明的临时重建素材；该文件不是原作者预设，透视与动画参数为参考重建。

视觉依据：本地 rhine_theme/docs/evidence/S02.jpg 所示的原主菜单浏览图，并参考明日方舟 UI 的透视关系。
