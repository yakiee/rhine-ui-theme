# 莱茵 UI 操作说明

适用版本：v0.13.46。当前模拟器已应用此版本。

## 桌面与切页

- 斜条主页设在第 2 个桌面。手指向右划，进入左边第 1 个正常应用桌面；在应用桌面向左划回到斜条主页。桌面翻页不再打开终端。
- 主屏右侧竖直 Dock 从上到下是：天气、音乐、日历、终端（四宫格）。点击四宫格在当前主题桌面展开终端，点击终端左上「返回」收起。
- 功能页用界面上的「返回 / ← / ×」退出，回到进入前的页面：从终端打开日历或音乐，返回终端；从斜条主页打开，则返回斜条主页。左右划到其他桌面时，主题界面自动收起。安卓系统返回键不承担主题内部切页。
- 主屏底部圆圈显示实际电量，满圈为 100%；旁边显示机器当前星期、日期。这部分用于显示，没有点击动作。
- 本版已移除主屏左上角的大时钟、AM/PM、机型铭牌和装饰短线。

## 各功能页

| 页面 | 操作 |
| --- | --- |
| 天气 | 点日期节点查看当天详情；详情中的前后按钮切换日期；点 × 收起详情。左上返回会先收起详情，再点一次回桌面。 |
| 音乐 | 显示正在播放的歌曲、封面；提供上一首、播放/暂停、下一首。先在播放器中开始播放。设置自定义音乐 App 后，主屏与终端的音乐入口均直接打开该 App。 |
| 日历 | 左右箭头切月，点日期选中当天；「回到今天」恢复当前日期，「系统日历」打开日历 App，右上 × 返回桌面。 |
| 原生应用桌面 | 点击启动器图标打开 App；长按移动、整理文件夹，上滑打开应用抽屉。这些图标由启动器管理，主题不会接管点击。 |
| 终端 | Dock 四宫格展开；左上「返回」收起，右上「主题配置」进入 KLWP 编辑器。 |

天气、歌曲信息和日程需要在 KLWP 中配置数据来源及相应权限。目前模拟器的天气和日程尚未接通，也没有正在播放的歌曲，因此显示等待或空值。

## 终端按钮

| 区域 | 点击后 |
| --- | --- |
| 顶端时间 | 打开主题日历 |
| 顶端四格电池 | 打开系统电池设置；格子按实际电量显示 |
| CPU / RAM / ROM | 分别进入设备信息、应用设置、存储设置 |
| 第一行左侧机温与加号、右侧封面 | 打开相册；机温为电池温度传感器的摄氏读数，加号是入口装饰 |
| 第一行中间「终端 / 系统」 | 打开设备信息 |
| 第二行「系统」 | 打开配置的 App，默认系统设置 |
| 第二行「音乐」 | 打开主题音乐页或配置的音乐 App |
| 蓝色行「支付宝 / 付款码 / 扫一扫」 | 分别打开支付宝首页、付款码、扫描入口；黑色「快捷支付」标题也进入支付宝首页 |
| 最后一行「电话 / 文件 / 微信」 | 分别打开拨号、文件管理、微信 |

灰色补位方块、背景纹理和分割线仅作装饰。相邻按钮虽然视觉相连，点击区域彼此独立，并有轻微按压反馈。

支付宝、微信及其他外部入口需要机器已安装对应 App。模拟器未安装支付宝、微信，支付入口尚未在这些 App 中实测。

## 修改壁纸、封面和 App

1. 斜条主页右侧 Dock 点最下面的四宫格，打开终端。
2. 点右上「主题配置」进入 KLWP 编辑器。
3. 打开「全局变量」，修改下列项目，然后保存。返回桌面查看效果。

| 全局变量 | 用途 |
| --- | --- |
| `homepg` | 斜条主页所在的桌面页码，默认 2；其他页只显示壁纸，交给启动器放 App |
| `wall` | 主屏壁纸 |
| `termcover` | 终端第一行的相册封面，可独立于壁纸设置 |
| `covertext` | 封面上的文字 |
| `musicapp` | 音乐 App 包名；留空使用主题音乐页，填写后两个音乐入口一起生效 |
| `musicsub` | 音乐按钮下面的小字 |
| `search` | 「系统」按钮对应的 App 包名，默认 `com.android.settings` |

App 包名不是显示名称，例如系统设置的包名为 `com.android.settings`。

## 安装版本

- `Rhine-UI-native-desktop-navigation-v0.13.46.klwp`：带手机倾斜视差。
- `Rhine-UI-native-desktop-navigation-off-v0.13.46.klwp`：关闭重力视差，其余交互一致。

在 KLWP 导入对应文件并保存为动态壁纸。启动器需要保留至少两个桌面并启用壁纸滚动。第 1 页放普通 App 图标，第 2 页留作斜条主页；若启动器支持默认主页，建议将第 2 页设为默认。其他页也可继续添加 App。主题内部的终端、天气、音乐、日历都在第 2 页打开，不占用新的启动器桌面。
