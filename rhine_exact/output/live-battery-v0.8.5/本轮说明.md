# 实时电量 v0.8.5

底部 BAT 圆环是电量进度：满圈对应 100%，半圈对应 50%，0% 仅显示暗灰底环。使用 KLWP 原生 Battery Progress 组件，数字读取 bi(level)，不再固定显示 78。100 的字号单独适配以避免截断。

终端三格电池使用相同的实时电量来源，分别在大于 0%、33.33%、66.67% 时亮起。

模拟器实际切换到 100%、50%、0% 并截图验证圆环与数字；测试后已重置电量模拟。普通版与静止版的结构和压缩包检查通过。仅电量所在的两个根模块有变更，原有动画轨道保持不变。

release 为本轮可用主题，off-release 为关闭重力视差的版本。iterations 保存已被替换的中间稿。
