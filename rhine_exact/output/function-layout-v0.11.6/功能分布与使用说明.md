莱茵 UI · 功能整理 v0.11.6

| 区域 | 功能与分工 |
| --- | --- |
| 首页侧栏 | 天气、音乐控制、日历、应用 |
| 终端上排 | 系统：安卓系统设置；主题：主题外观与交互 |
| 蓝色支付区 | 支付宝主页、支付宝付款码、支付宝扫一扫；集中在一个区域 |
| 终端下排 | 电话、文件、微信；替换重复的付款码和扫码 |
| 应用页 | 浏览器、相册、时钟、地图、邮件、短信、联系人、云盘 |
| 底条 | 关闭、日期或电量显示，不再重复提供功能导航 |

首页左滑到终端，终端右滑返回。应用及其他功能子页使用左上角返回；快速切换桌面后点入口不会被延迟的切页事件取消。

应用页的图标、名称和动作现在一致。主题仍可逐项编辑，保留两页桌面、透视、缩放渐隐、重力视差和实时设备数据。

本机验证：系统设置、主题设置、电话、文件、时钟和应用页返回。微信、支付宝未安装在模拟器中，其主页/付款码/扫码链接没有做实际应用内验证。电话、文件与云盘绑定了当前模拟器的应用组件；换手机后若对应入口无法打开，可在 KLWP 的触摸动作中选取该手机的应用。其他应用使用系统默认应用入口。

导入预设后，桌面启动器与 KLWP 均保持横向两页并启用壁纸滚动。文件名含 off 的版本关闭重力视差。
