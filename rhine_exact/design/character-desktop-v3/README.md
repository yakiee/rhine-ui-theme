# 庄方宜人物互动桌面 v3

此版取代 v2 中底部常驻 App Dock 的方案。设计日期：2026-09-15。

- 待机：人物、壁纸、原有斜条，无常驻 App 图标，无右侧工具塔。
- 点手掌：翻掌、技能光标亮起，再展开电话、微信、浏览器。App 绑定可配置。
- 点腰间挂件：局部光效，展开相机、相册、文件。其他分组后续按需增加。
- 点浮出的 App 才跳转；点空白或开始左右翻页收起菜单。
- 保留原底部斜条的电量圆环、星期、日期及原有跟手收拢交互。配色改为壁纸取色的半透明墨绿至橄榄金渐变。
- 不增加底部常驻 App，不使用上版水平信息卡，不改变为静态工具栏。

本图由内置 imagegen 根据人物外观描述生成，为三个交互状态的概念稿；生成图中人物为重新演绎，实际制作需统一回现有庄方宜素材。图片不代表已制作出 Live2D 动画，也未应用到手机。图中日期、电量为示意值，落地仍使用设备数据。现有手机的斜条几何和动画以运行版本为准，设计图仅表达保留其形式并调整材质。
